디몰비전 (DimolVision)

철거 현장 사진으로
견적의 출발점을 만듭니다

소재 식별 · 철거 공정 · 위험요소 경고 · 폐기물 물량과 운반 트럭 대수까지. 아래 버튼을 누르면 바로 체험할 수 있습니다.

서비스 체험하기 →
✓ 회원가입·로그인 없이 모든 기능을 이용할 수 있습니다. 테스트 계정이 필요 없습니다.

30초 체험 순서

  1. 샘플 사진 누르기 상단 샘플로 바로 체험 영역에서 사진 3장 중 하나를 클릭합니다. 실제 철거 현장 사진이며, 누르는 즉시 AI 분석이 시작됩니다(약 10~20초).
  2. 분석 리포트 확인 구성 소재와 예상 중량, 권장 철거 공정, 안전 위험요소가 순서대로 나옵니다. 결과 상단 칩이 AI 분석 결과이면 그 사진을 실제 모델이 분석한 것입니다(미리 써둔 고정 응답이 아닙니다).
  3. 건물 정보 입력 후 재분석 연면적에 40, 건축년도에 1985를 넣고 “면적 반영해 다시 분석”을 누르면 예상 톤수·운반 트럭 대수와 함께 견적 기초자료가 추가됩니다. 1985년은 석면 사용 금지(2009년) 이전이라 석면 의심 판단이 달라지는 것도 보실 수 있습니다.
  4. 직접 촬영한 사진으로 테스트 “앨범에서 선택”으로 여러 장을 한 번에 올리면 종합 분석합니다. 사진이 많을수록 식별되는 소재가 늘어납니다.

확인 포인트

여러 장 종합 분석

한 장일 때보다 여러 장을 함께 보면 식별 소재가 늘어납니다. 한 각도에서만 보이는 자재를 다른 사진이 보완합니다.

견적으로 이어지는 출력

“석고보드가 있습니다”에서 끝나지 않고 법정 폐기물 분류별 배출량, 투입 장비, 예상 공기·인력, 운반 트럭 대수까지 산출합니다.

모르는 것을 밝히는 설계

내력벽 여부·지중 구조물·도로 폭처럼 사진으로 알 수 없는 항목을 현장 실사 확인 목록으로 따로 제시합니다.

끊기지 않는 분석

여러 비전 모델을 우선순위로 시도해, 한 곳이 응답하지 못해도 다음이 이어받습니다.

석면을 다루는 방식

석면은 사진만으로 판별할 수 없고, 석면안전관리법상 해체 전 전문기관 조사가 의무입니다. 그래서 이 서비스는 “석면입니다 / 석면이 없습니다” 같은 확정 표현을 절대 출력하지 않습니다. 모델이 확정 표현을 내더라도 응답 단계에서 “석면 의심 · 전문 조사 필요”로 교정합니다.
